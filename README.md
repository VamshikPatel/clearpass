### Features & Architecture
1. **Motion.dev × A24 Aesthetic Direction:**
   - Obsidian pitch-black palette (`#070708`), hairline 1px architectural grids, subtle film-grain texture overlay (`opacity: 0.035`).
   - Single high-voltage accent: Acid Volt (`#E8FF47`) reserved strictly for live actions, active nodes, and verified seals.
   - Typography: `Instrument Serif` editorial display, `Inter` UI sans, `JetBrains Mono` metadata.
   - Snappy spring physics (`stiffness: 380, damping: 32`), shared layout sliding pills, and tactile `scale: 0.97` tap compression.
2. **Sequential Multi-Desk Routing Rail:**
   - Official VVCE sequence: `LIBRARY ➔ HOSTEL ➔ ACCOUNTS ➔ LAB ➔ HOD`.
   - Live elapsed wait time and status tracking.
3. **Department Officer High-Density Ledger Table:**
   - A24 film-credits aesthetic with inline expanding triage drawers (`APPROVE`, `NEEDS CORRECTION`, `REJECT`) and required remarks.
4. **Collector's Pass Artifact & Dynamic Pure SVG QR Code:**
   - SHA-256 cryptographic verification digest.
   - Animated SVG checkmark path in authentic `#E8FF47` seal.
   - Print-ready CSS for one-click official PDF export.
5. **Administrative Audit & UN SDG Analytics:**
   - 4-column KPI strip: Turnaround time (4.2h vs 4.5 days), active pipeline count, cleared volume, bottleneck delay visualization.
   - UN SDG 4, 12, 16 impact ledger.

### Running the Application

#### Option A: 1-Click Instant Demo (No Installation Required)
Double-click `index.html` in this folder to open directly in Google Chrome or Microsoft Edge. All features, interactive role switching, requests, and QR codes work 100% offline!

#### Option B: Full-Stack Server (Python + SQLite)
Run:
```bash
python server.py
```
Or double-click `run_clearpass.bat`.  
Access at: `http://localhost:5000`
